Cloud Architecture Overview

About MedTrack Platform

MedTrack is a cloud-based healthcare management system that streamlines patient-doctor interactions by providing a centralized platform for booking appointments, managing medical histories, and enabling diagnosis submissions.

Key AWS Infrastructure Capabilities

AWS EC2 & Nginx

Scalable production hosting handling high request volumes seamlessly without latency.

Amazon DynamoDB

NoSQL key-value database storing PatientID, DoctorID, AppointmentID, and Diagnosis records.

AWS IAM Governance

Role-based access control protecting sensitive health records with strict policy enforcement.

Amazon SNS Alerts

Instant SMS & Email notifications triggered automatically upon appointment updates.
